# Support

Thanks for using upload-file! Here is how to get help.

## Documentation

Start with the docs in this repository:

- [README](README.md) — quick start and coordinates
- [Features & Functionality](docs/FEATURES.md)
- [HTTP API reference](docs/API.md)
- [Design](docs/DESIGN.md)

## Bug reports & feature requests

Open a GitHub issue using the [issue templates](https://github.com/FoamValue/upload-file/issues/new/choose):

- `Bug report` — include module/version, reproduction steps, environment and logs
- `Feature request` — include the problem, proposed solution and compatibility impact

Please search the [existing issues](https://github.com/FoamValue/upload-file/issues) first to
avoid duplicates.

## Questions & discussion

For questions and ideas, open a discussion in the
[GitHub Discussions](https://github.com/FoamValue/upload-file/discussions) forum.

## Security vulnerabilities

Do **not** open a public issue for security problems. Follow the private reporting channels in
[SECURITY.md](SECURITY.md).

## Version compatibility

`1.0.0` is a GA release with a frozen API. Breaking API changes are not expected within the
`1.x` line; the CI binary-compatibility gate enforces this. See the
[V1.0.0 SOW / API freeze](docs/PLAN-V1.0.0.md) for details.
