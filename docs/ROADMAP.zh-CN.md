# 未来优化方向

## 当前优化计划

- P0 项（5 项）已在 **V1.0.0-rc.2** 实现（原始拆解见 [V1.0.0 任务开发计划](PLAN-V1.0.0-rc.2.zh-CN.md)）。
- **V1.0.0-rc.3 生产就绪加固**（访问控制 / 多实例约束 / 大小配额 / 可观测 / 迁移工具 / compat 回归 / 1.0.0 范围定义）已排期，见 [V1.0.0-rc.3 任务开发计划](PLAN-V1.0.0-rc.3.zh-CN.md)。
- P1/P2 项排期待确认。

## 完整优化列表

以下为后续升级的可选方向。P0 项已在 `1.0.0-rc.2` 实现；P1/P2 项尚未实现，按优先级从高到低排列。

| 优先级 | 方向 | 解决问题 | 要点 | 提出时间 | 计划上线版本 |
| --- | --- | --- | --- | --- | --- |
| P0 ✅ | 过期任务清理（TTL/GC） | 未合并完成的残留任务与分片无过期机制，长期运行无限堆积占用磁盘 | 基于 `UploadTask.updateTime` 增加定时清理或可配置 TTL | 2026-08-25 | V1.0.0-rc.2 已实现 |
| P0 ✅ | 合并原子化 | merge 中途崩溃留下坏文件 | 先合并到同目录临时文件，成功后 rename 再更新元数据 | 2026-08-25 | V1.0.0-rc.2 已实现 |
| P0 ✅ | 孤儿数据治理 | 元数据丢失后残留分片/文件无法回收 | 启动扫描 + 周期对比 TaskStore 与磁盘，清理孤儿 | 2026-08-25 | V1.0.0-rc.2 已实现 |
| P0 ✅ | 合并异步化 | 大文件 merge 阻塞 HTTP 请求、易超时 | 任务队列 + 回调/轮询进度 | 2026-08-25 | V1.0.0-rc.2 已实现 |
| P0 ✅ | 元数据扩展存储 | 多节点/高可用 | Redis/DB 版 TaskStore（现有 SPI 已留口） | 2026-08-25 | V1.0.0-rc.2 已实现 |
| P1 | 多租户隔离 | 多人/多业务共用一套部署 | identifier 加命名空间前缀，互不可见、各自配额 | 2026-08-25 | 无（动态更新） |
| P1 | 配额与限速 | 单用户容量上限、全局限速 | 上传/下载限速、总容量与单文件大小配额 | 2026-08-25 | 无（动态更新） |
| P1 | 秒传（判定策略 B） | 重复上传大文件浪费带宽与时间 | 仅当 TaskStore 中 identifier 存在且 `merged=true`、最终文件在磁盘上时才秒传；触发点为 `getProgress` 或首次 `uploadChunk`；前提：配置 `upload-file.metadata-dir`（FileTaskStore），否则重启后失效；边界：OS 手动拷入 `files/<id>/` 的文件不触发秒传 | 2026-08-25 | 无（动态更新） |
| P1 | 内容一致性校验 | 服务端不校验整文件哈希，无法保证内容与 identifier 真的一致 | identifier 约定由整文件 MD5 升级为整文件 SHA-256；merge 后服务端重算合并文件 SHA-256 并与 identifier 比对，不一致则删除合并文件并抛错；联动改动客户端哈希算法、`ChecksumUtil`、`chunkMd5` 语义、文档/演示/测试 | 2026-08-25 | 无（动态更新） |
| P1 | 单副本 + 别名索引（存储模型） | 同内容不同文件名重复占盘、别名无法下载 | 物理文件存于 `files/<identifier>/<identifier>`，同内容只存一份；别名索引 `identifier → List<fileName>`（含上传时间等元数据）；秒传 = 新文件名加入别名表；下载按 identifier 解析物理文件，`Content-Disposition` 用指定别名（下载 API 需扩展支持按别名取或返回别名列表） | 2026-08-25 | 无（动态更新） |
| P1 | 跨任务分片内容去重 | 多个相似文件含大量相同分片各存一份，磁盘浪费 | 以分片 MD5 为存储键 + 引用计数，相同内容只落一份，合并时按引用组装；注意：当前固定偏移切片，仅当文件差异与分片边界对齐时相同分片才较多；更强去重需引入内容定义分片（CDC），但会改变分片边界与断点续传语义 | 2026-08-25 | 无（动态更新） |
| P1 | 支持 tus 协议 | 客户端接入成本高、生态割裂 | tus 是分片续传事实标准，兼容后前端 SDK 直接复用 | 2026-08-25 | 无（动态更新） |
| P1 | 多语言 SDK | 只给 HTTP 协议，业务方集成成本高 | Java/JS/Python，封装分片、重试、断点续传 | 2026-08-25 | 无（动态更新） |
| P1 | 对象存储后端 | 单机盘满、无扩展性 | 用现有 `ChunkStorage` SPI 接 S3/MinIO/OSS；或客户端直传+服务端签名协调 | 2026-08-25 | 无（动态更新） |
| P1 | 回收站/软删除 | 误删不可恢复 | 删除先标记，TTL 后异步物理删除 | 2026-08-25 | 无（动态更新） |
| P1 | 审计日志 | 合规与追溯 | 上传/下载/秒传全量留痕 | 2026-08-25 | 无（动态更新） |
| P2 | 病毒扫描 | 上传文件可能含恶意内容 | 上传完成异步扫描（ClamAV），未通过前不可下载 | 2026-08-25 | 无（动态更新） |
| P2 | 文件类型白名单 + 魔数校验 | 可上传可执行文件/伪装类型 | 扩展名白名单 + 文件魔数校验 | 2026-08-25 | 无（动态更新） |
| P2 | 预签名下载链接 | 分享缺少时效与访问控制 | 带过期时间、密码、次数限制的分享 | 2026-08-25 | 无（动态更新） |
| P2 | 版本管理 | 同 identifier 重传会覆盖历史版本 | 重传保留历史版本 | 2026-08-25 | 无（动态更新） |
| P2 | 静态加密 | 数据落盘明文 | 磁盘层加密或字段级加密 | 2026-08-25 | 无（动态更新） |
| P2 | 压缩 | 大文件占用带宽与磁盘 | 按内容类型透明压缩，省带宽省盘 | 2026-08-25 | 无（动态更新） |
| P2 | 预览/转码 | 无法在线预览图片/视频 | 图片缩略图、视频转码，与上传管线解耦 | 2026-08-25 | 无（动态更新） |
| P2 | Webhook | 业务方无法感知上传完成事件 | 上传完成/秒传命中事件推送 | 2026-08-25 | 无（动态更新） |
| P2 | 可观测 | 缺乏指标与运维视图 | Prometheus 指标、结构化日志、管理后台（存储统计、任务查询） | 2026-08-25 | 无（动态更新） |
