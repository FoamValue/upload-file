# upload-file

Maven toolkit for **large-file chunked upload / resumable (breakpoint) upload / HTTP `Range`
resumable download**. Pure Java, compatible with JDK 8 and above. Published to Maven Central as
`cn.chenxinjie:*` (1.0.0 GA).
